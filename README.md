# What is it for?
Help tech 3 subsystem manufacturers in EVE Online compare different subsystems and keep track of their costs.

# How does it work?
The accompanying [API](https://github.com/EFawke/EveSubsystemAnalysis) fetches market data for all of the materials required to build subsystems as well as the subsystems themselves on a nightly basis.
In addition, a 30 minute cache makes sure prices displayed are up to date.
Loss data from zkillboard is also collected, cleaned and stored to give an indication of demand for different subsystems.

# How does this help manufacturers?
The manufacturing process for tech 3 subsystems is complex.
There are around 30 different variables which all have an impact on the quantity of raw materials needed.
The build page simplifies this. A user can input their current in-game setup and get an exact price for everything they'll need.
Included are quality of life features like the ability to copy the materials from the site and paste them in the game, and a [reaction scheduler](https://tedfawke.com/blog/optimising-reaction-schedules-in-eve-online) that displays the fastest possible schedule for the user.
